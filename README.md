## Overview

This project implements a production-quality, modular, and explainable framework for detecting phishing communications generated by Large Language Models (LLMs). It specifically targets the **Nigerian financial sector**, distinguishing between:

| Class | Label | Description |
|-------|-------|-------------|
| ✅ Legitimate | 0 | Authentic bank communications (debit alerts, transfer confirmations, KYC reminders) |
| ⚠️ Traditional Phishing | 1 | Poorly crafted phishing attempts with grammatical errors and suspicious links |
| 🚨 AI-Generated Phishing | 2 | Sophisticated, professionally written phishing messages generated by AI |

**Key Innovation:** Uses **semantic analysis** (DistilBERT) rather than keyword matching, combined with **SHAP explainability** to show *why* each message was flagged.

## Dataset

### Distribution
- **1,561** Legitimate Financial Communications
- **1,689** Traditional Phishing Messages
- **1,750** AI-Generated Phishing Messages
- **Total:** 5,000 samples

### Data Sources
- **Legitimate:** Realistic Nigerian bank communications (debit alerts, transfer confirmations, password resets, KYC reminders, ATM withdrawal notifications)
- **Traditional Phishing:** Poor grammar, urgent calls-to-action, suspicious URLs
- **AI-Generated Phishing:** Perfect grammar, professional tone, psychological manipulation, CBN directive impersonation

### Financial Institutions Covered
GTBank · UBA · Access Bank · Zenith Bank · Fidelity Bank · First Bank · Moniepoint · PalmPay · Opay · Stanbic IBTC · Ecobank · Union Bank · Wema Bank · FCMB · Kuda · Carbon · Interswitch · Flutterwave · Paystack

## Explainability (SHAP)

The SHAP explainer identifies which words most influenced the model's prediction:

```python
from explainability.shap_explainer import explain_text

result = explain_text("Your account has been suspended...")
print(result["explanation"])
# Output:
# "This email was classified as 'AI-Generated Phishing' with 94.3% confidence
# because it exhibits sophisticated social engineering techniques, professional
# yet manipulative language, and authority-based psychological persuasion.
# The words 'suspended', 'compliance', 'immediately', 'validate', 'restricted'
# contributed significantly to the prediction."
```

*Actual results depend on dataset quality and training hyperparameters.*

### Caveat on Perfect Test-Set Scores

If the model reports a perfect **1.0000** score across all five evaluation
metrics (Accuracy, Precision, Recall, F1-Score, and AUPRC) on the held-out
test set, this should **not** be interpreted as evidence of guaranteed
real-world performance. The most likely explanation is that near-duplicate or
template-sibling AI-generated phishing samples — built around a small number
of named fraud scenarios with minor slot substitutions — ended up on both
sides of the 80/10/10 split.

The preprocessing pipeline performs **exact-string deduplication only** (see
`preprocessing/preprocessing.py`). It does not detect semantic or
near-duplicate samples. Before submission, run the data-integrity validation:

```bash
# Full check (includes optional embedding cosine similarity, slower)
python validation/data_integrity.py

# Fast check (n-gram overlap only, no model loading required)
python validation/data_integrity.py --fast
```

This script checks:
- **(i)** Near-duplicate overlap between train/test AI-generated samples
  (character 3-gram Jaccard + optional DistilBERT embedding cosine similarity)
- **(ii)** Whether template families span both train and test splits
- **(iii)** Confusion matrix text reproduction for direct verification

The evaluation pipeline (`evaluation/evaluate.py`) also outputs the confusion
matrix as both a **PNG image** and a **text file** (`confusion_matrix.txt`)
so the zero-misclassification result can be verified directly.

### Remediation Steps (before submission)

1. Run `python validation/data_integrity.py` and review the report
2. Consider applying near-duplicate removal (cosine > 0.90 or Jaccard > 0.80)
   before splitting, or use group-based splitting to keep template families
   together
3. If possible, evaluate on a genuinely external test set drawn from prompts
   and scenario wording never used during dataset construction
4. Report the confusion matrix values as text in the surrounding paragraph,
   not only as an embedded image
